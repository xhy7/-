### P0-02 · 扩展 `use-pet-controller` 面板状态

- [ ] 新增 `activePanelId: DesktopPetPanelId`，初始值 = `config.defaultPanelId`

- [ ] 面板切换时可选应用 `quickIntent.prompt` 或 `panelItem.summary` 到台词气泡

| 面板 | 动作 |
|------|------|
| profile | `greet` |
| growth | `happy` |
| playground | `talk` 或 `poem`（优先 `panelItem.actionState`） |
| chat | `talk` |

- [ ] 小屏：舞台在上、面板在下（或 P2 升级为底部抽屉）
- [ ] `PetPanelTabs` 置于面板顶部或舞台与面板之间
- [ ] 保留 header / identityRow，文案可微调为「面板驱动」语境

**验收（Dev2 范围）**：`DesktopPetHub` 内部主区域为「舞台 + 面板」双栏；默认展示 `defaultPanelId` 对应面板内容。
